# 🛍️ VitrineIA — Inteligência Comercial para Lojistas

> **Transformando dados de visitantes e vendas em decisões estratégicas para lojistas de shopping.**

## 📌 Sobre o Projeto
A **VitrineIA** conecta o comportamento em tempo real dos visitantes de um shopping center com os lojistas. Por meio de totens com QR Code oferecendo recompensas instantâneas, coletamos intenções de compra de forma anonimizada (LGPD), cruzamos com dados comerciais e utilizamos **Mineração de Dados + IA Generativa** para sugerir campanhas conjuntas e oportunidades de vendas.

- **Backend:** Java - Spring Boot
- **Banco de Dados:** PostgreSQL
- **Inteligência & Dados:** Regras de Associação (Mineração de Dados) + API de IA Generativa
